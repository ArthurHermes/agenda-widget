App do Google (configurar uma vez)

Para ler e editar sua agenda, o widget precisa de um “app” OAuth seu no Google Cloud. É gratuito.

Como criar o Client ID e o Client Secret
  1. Abra o Google Cloud Console e crie um projeto (ex.: “Agenda Widget”).
  2. Ative a Google Calendar API nesse projeto.
  3. Em Google Auth Platform, clique em Começar: dê um nome, escolha Externo e informe seu e-mail.
  4. Em Público-alvo, clique em Publicar app (para colocá-lo “Em produção”). Se ficar em “Teste”, adicione cada e-mail que for conectar como usuário de teste, mas o login expira a cada 7 dias.
  5. Em Clientes, clique em Criar cliente, escolha o tipo App para computador e copie o ID do cliente e a Chave secreta para os campos abaixo.
  6. No login, o Google avisa que o app não foi verificado. Como o app é seu, clique em Avançado → Acessar.

Links iCal (somente leitura)

Útil para agendas que você não consegue conectar como conta, como feriados ou agendas de terceiros. Na Google Agenda: Configurações → agenda → Integrar agenda → Endereço secreto no formato iCal.

Comportamento

Não atrapalhar o que está atrás

Os cliques vão direto para os ícones e janelas atrás do widget. Para usar o widget (clicar num evento, arrastar, botões), segure Ctrl com o mouse em cima dele: aparece uma borda colorida. Também dá para ligar e desligar pelo ícone na bandeja.

Um clique no ícone da bandeja esconde ou mostra o widget.

Para iniciar junto com o Windows, use o ícone do widget na bandeja do sistema.
